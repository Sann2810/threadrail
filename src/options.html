A rail for your other conversations.

ChatGPT, Claude, and Gemini are detected automatically. For another chat website, enable access to that site. If its messages use standard role attributes, the rail will work automatically.

Access is requested for this website only. Chat snapshots are saved in your local library and never sent to a search server.

Advanced: configure message selectors for this website

For interfaces with a custom layout, identify the conversation area and the user and assistant message elements. Selectors are CSS only; no scripts run from this form.

This extension runs inside Chromium web pages. Native Codex and Claude desktop windows, terminal sessions, IDE webviews, and browser panes that do not support extensions require separate host integrations. Enabling a website does not add controls to those applications.

Stored locally: chat library, search vectors, site preferences and CSS selectors. Manage or clear saved chats in the All chats library. No cloud search or analytics.
